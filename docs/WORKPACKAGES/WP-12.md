## What to build

- `symbology/manned.ts`: a distinct icon family for manned aircraft
  (plane silhouette), colour by trust (`surveillance` vs `broadcast`),
  opacity by age bucket, label `callsign` or `icao24`, emergency halo.
- `MannedLayer`: as `TrackLayer` for `MannedView`, no identification,
  `staleAfterS` and `nowMs` required; a manned track never disappears
  on its own: the app removes it with a reason from the store.
- `symbology/intent.ts`: fill and outline per `dssState`
  (`Accepted` thin, `Activated` solid, `Nonconforming` warning colour,
  `Contingent` critical colour) and a `peer` variant (diamond pattern
  for another USSP's intent via the DSS), `selected` emphasis.
- `IntentLayer`: footprints from `volumes` (GeoJSON polygons as the API
  derived them: the kit does not build a polygon from a circle or an
  altitude band), labels with the authorisation number, a time window
  note in the hover card (`timeStart`–`timeEnd` UTC); the "current"
  emphasis uses a prop `activeIds` the app computed from the API's
  state, not a time comparison in the kit.
- `ReceiverLayer`: receiver positions with `SourceState` icon (B-11
  words in the hover card: `disabled by <who>`, `silent since T`,
  `healthy`), click → `onSelect`.
- `TrackDetail`: the panel for a selected `TrackView` or `MannedView`:
  identification block (status, reason hint, basis caveat, mismatch
  line, registration public part, serial), position, altitudes each
  with datum (`altAmslM` "AMSL", `altWgs84M` "ellipsoid", `heightM`
  with `heightRef`, `pressure` source marked), speed, track, vertical
  speed, emergency, trust with its meaning, source and instance (the
  receiver for a broadcast track, "heard by"), `times` (`ts`, `rxTs`,
  `capturedAt` each labelled, `timeSource`, `backlog` badge), ages, the
  flight and intent ids as links the app provides via a render prop.
  Every number through WP-2's formatters; every null a dash.

## Safety notes

The traffic picture is what a remote pilot uses to avoid a collision
(Art. 11(4)). Two rules dominate: never hide (a stale or unavailable
source is shown as such, a manned track is never dropped by the client)
and never upgrade (a broadcast ADS-B or Remote ID track stays visibly
unverified). The intent footprint is the authorised volume as the USSP
computed it; the kit does not derive it, and does not decide which is
"current".
